# เมนูซ้ายลากปรับขนาดได้ พร้อมแท็บขอบสำหรับย่อ/ขยาย

วันที่ 25 พ.ย. 2569 · ผู้ขอ: wasan

## ทำไม

ผู้ใช้อยากได้พื้นที่ทำงานกว้างขึ้นเวลาต้องการ โดยคงหน้าตาเดิมของระบบทั้งหมด (ผู้ใช้สั่ง "คงดีไซน์เดิมไว้ก่อน" แล้วขอเฉพาะเมนูซ้ายที่ย่อ/ขยายได้แบบ B)

## สิ่งที่ตกลงกัน (ผ่านต้นแบบที่กดทดลองได้)

- ลากเส้นขอบขวาของเมนูซ้ายเพื่อปรับความกว้างได้ (ผู้ใช้เลือก "ลากปรับขนาด" จาก 5 แบบการย่อ)
- บนเส้นขอบมี **แท็บขอบ** (แบบ 4 จาก 5 แบบปุ่ม): แท็บสีน้ำเงินเดียวกับเมนู มุมขวามน ยื่นออกจากขอบกลางความสูง มีจุดจับบนล่างและลูกศร กดเพื่อย่อ/ขยาย จับลากเพื่อปรับความกว้างได้
- ลากแคบกว่า 170px เมนูจะกลายเป็นราง 92px แบบ B: ไอคอนอยู่บน ชื่อเมนูตัวเล็กอยู่ใต้ไอคอน (ไม่เกิน 2 บรรทัด) ตัวเลขงานรอย้ายไปมุมไอคอน ซ่อนชื่อระบบเหลือโลโก้ ปุ่มออกจากระบบเหลือไอคอน
- ความกว้างกว้างสุด 360px ค่าเริ่มต้น 272px (เท่าเดิม)
- กดแท็บตอนเป็นรางจะกลับไปความกว้างล่าสุดที่ไม่ใช่ราง
- ระบบจำความกว้างไว้ (cookie) เปิดหน้าใหม่ไม่กระพริบ เพราะเซิร์ฟเวอร์อ่าน cookie แล้ววาดความกว้างตั้งแต่แรก
- Ctrl B ย่อ/ขยายได้ (ยกเว้นขณะพิมพ์ในช่องกรอก)
- แป้นพิมพ์: แท็บเป็นปุ่มจริงพร้อม aria-expanded; เส้นขอบเป็น `role="separator"` ใช้ลูกศรซ้ายขวาปรับทีละ 24px
- จอแคบกว่า 720px เหมือนเดิม (เมนูอยู่บนหน้า 2 คอลัมน์ ไม่มีเส้นลาก)
- แถบขาวหน้าปัจจุบัน แสงเรือง ป้าย "พัฒนา" และสีโมดูลคงเดิม แถบขาวต้องเลื่อนตามเมื่อความกว้างเปลี่ยน

## ไม่ทำ (non-goals)

- ไม่เปลี่ยนสี ฟอนต์ หรือโครงหน้าอื่น
- ไม่เก็บความกว้างในฐานข้อมูล (เครื่องใครเครื่องมัน)

## แนวทางที่พิจารณา

1. ไอคอน + ชื่อใต้ (ปุ่มใต้โลโก้) 2. ไอคอนล้วน 3. ชี้แล้วกางทับ 4. ซ่อนทั้งแถบ 5. ลากปรับขนาด — ผู้ใช้เลือก 5
ปุ่มบนเส้นลาก: กลางเส้น / บนสุด / ตามเมาส์ / แท็บขอบ / สามขนาด — ผู้ใช้เลือกแท็บขอบ

## การทำ (การตัดสินใจของผู้สร้าง)

- `lib/sidebar-width.ts` ฟังก์ชันล้วน: ค่าคงที่, `clampSidebarWidth`, `parseSidebarCookie`, `serializeSidebarCookie`, `nextToggleWidth`
- `ShellFrame` ถือ state ความกว้าง ใส่ `--sidebar-w` และ `data-sidebar="rail"` บน `.app-shell`
- `components/sidebar-edge.tsx` วาดเส้นขอบ (position fixed ที่ `left: var(--sidebar-w)`) และแท็บขอบ
- `(app)/layout.tsx` อ่าน cookie `bo_sidebar` ส่งให้ `AppShell`
- `SidebarNav` ห่อชื่อด้วย `.nav-label` และวางแถบขาวใหม่เมื่อความกว้างเปลี่ยน (ResizeObserver)
