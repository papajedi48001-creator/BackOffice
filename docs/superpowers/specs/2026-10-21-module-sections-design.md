# เมนูย่อยอยู่ในโมดูลของตัวเอง

ผู้ขอ: wasan — "ให้เมนูย่อยแต่ละเมนูที่แสดงในหน้าหลักไปอยู่ใน โมดูลของตัวเอง"

## ปัญหา

หน้าหลักและแถบเมนูด้านข้างแสดงหน้าย่อยของโมดูลเดียวกันเป็นปุ่มแยก: บุคลากร, หน่วยงาน, นำเข้าข้อมูลตั้งต้น (โมดูลบุคลากร) และ บทบาทและสิทธิ์, ผู้แทน (โมดูลสิทธิ์) ขัดกับกติกาใน `docs/integration/modules.md` ที่ให้หน้าย่อยลิงก์จากหน้าโมดูลเอง

## พฤติกรรม

- หน้าหลักและเมนูด้านข้างมีหนึ่งปุ่มต่อหนึ่งโมดูล
  - `hr` "บุคลากร" → `/hr` มีเมนูย่อย บุคลากร (`/hr/people`), หน่วยงาน (`/hr/organizations`), นำเข้าข้อมูลตั้งต้น (`/hr/imports`)
  - `access` "สิทธิ์และผู้แทน" → `/access` มีเมนูย่อย บทบาทและสิทธิ์ (`/access/roles`), ผู้แทน (`/access/delegations`)
- ปุ่มโมดูลแสดงเมื่อผู้ใช้เห็นเมนูย่อยอย่างน้อยหนึ่งเมนู เงื่อนไขการเห็นเมนูย่อยแต่ละเมนูเหมือนเดิม
- ทุกหน้าในโมดูลมีแถบเมนูย่อยด้านบน แสดงเฉพาะเมนูที่ผู้ใช้เห็น เมนูที่อยู่ปัจจุบันมี `aria-current="page"`
- เปิด `/hr` หรือ `/access` ตรง ๆ ระบบพาไปเมนูย่อยแรกที่ผู้ใช้เห็น ถ้าไม่เห็นเลยแสดง "คุณไม่มีสิทธิ์ดูข้อมูลส่วนนี้"
- การซ่อนเมนูไม่ใช่การกันสิทธิ์: หน้าและ API ยังตรวจสิทธิ์เองเหมือนเดิม
- เมนูด้านข้าง "บุคลากร" เป็นหน้าปัจจุบันเมื่ออยู่หน้าใดก็ได้ใต้ `/hr/`
- จองห้องประชุมมีหน้าย่อยลิงก์จากหน้าโมดูลอยู่แล้ว ไม่เปลี่ยน

## โครงสร้าง

- `ModuleEntry.sections?: ModuleSection[]` ใน `apps/web/src/lib/modules.ts` (`{ href, labelKey, visible(subject) }`) และ `moduleSections(code, subject)` คืนเมนูย่อยที่ผู้ใช้เห็น
- `components/module-subnav.tsx` แถบเมนูย่อย
- `app/(app)/hr/layout.tsx`, `app/(app)/access/layout.tsx` แสดงแถบ; `hr/page.tsx`, `access/page.tsx` redirect
- โมดูลใหม่ที่มีหน้าย่อยใช้ `sections` แบบเดียวกัน (เพิ่มในคู่มือการเชื่อมโมดูล)

ไม่มี migration ไม่มีการเปลี่ยนสิทธิ์
