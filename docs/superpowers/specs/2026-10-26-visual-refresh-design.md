# ปรับหน้าตาระบบให้ทันสมัย และสีประจำโมดูล

ผู้ขอ: wasan — "ปรับปรุงหน้าเว็บให้ดูทันสมัย สวยงาม เป็นมืออาชีพ เหมาะสมกับองค์กร หน้าหลักใช้โทนสีเขียวสาธารณสุข แต่ละโมดูลใช้โทนสีแตกต่างกันตามความเหมาะสม"

## พฤติกรรม

- ทุกหน้าที่ล็อกอินแล้ว: แถบซ้ายสีเขียวเข้มสาธารณสุขพร้อมตราระบบ, พื้นหลังเขียวอมเทาอ่อน, การ์ดขาวมุมโค้ง 12–14px เงาบาง
- หน้าหลัก (`/dashboard`) และหน้าเข้าสู่ระบบใช้สีหลักเขียวสาธารณสุข `#0E7C47`
- แต่ละโมดูลมีสีประจำ ใช้กับปุ่มหลัก ลิงก์ แถบเมนูย่อย หัวตาราง ขอบซ้ายของฟอร์ม และแถบสีด้านบนของพื้นที่ทำงาน เมื่อผู้ใช้อยู่ในโมดูลนั้น
- ปุ่มโมดูลบนหน้าหลักใช้สีของโมดูลนั้นที่ไอคอน และเส้นขอบตอน hover; รายการในแถบซ้ายมีจุดสีของโมดูล
- สีสถานะ (รอ/อนุมัติ/ไม่อนุมัติ) และสีเตือน (`alert`) คงความหมายเดิมทุกโมดูล ไม่ใช้สีโมดูลแทนสถานะ

| โมดูล | รหัส | สี | เหตุผล |
|---|---|---|---|
| หน้าหลัก | home | `#0E7C47` เขียวสาธารณสุข | สีองค์กร |
| คำขอ | requests | `#1D4ED8` น้ำเงิน | งานเอกสาร/อนุมัติ |
| การแจ้งเตือน | notifications | `#6D28D9` ม่วง | แยกจากงานหลัก |
| การลา | leave | `#BE185D` ชมพูเข้ม | งานบุคคลส่วนตัว |
| งานบุคคล | hr | `#0F766E` เขียวน้ำทะเล | ใกล้สีองค์กร |
| จองห้องประชุม | room-booking | `#0369A1` ฟ้า | ทรัพยากรสถานที่ |
| คลังพัสดุ | inventory | `#B45309` อำพัน | พัสดุ/วัสดุ |
| สิทธิ์และการตรวจสอบ | access | `#475569` เทาฟ้า | งานกำกับ เป็นกลาง |

ทุกสีผ่านอัตราส่วนความต่างสี 4.5:1 กับตัวอักษรขาว (WCAG AA)

## โครงสร้าง

- `styles.css` ใช้ CSS variables: `--accent`, `--accent-strong`, `--accent-soft` (คำนวณด้วย `color-mix`) และ `--ink`, `--muted`, `--line`, `--surface`, `--page` แทนค่า hex ที่ฝังไว้
- `[data-module="<code>"]` กำหนด `--accent` ของโมดูล ใช้ได้ทั้งกับ shell และปุ่มบนหน้าหลัก
- `moduleCodeForPath(pathname)` ใน `lib/modules.ts` หาโมดูลจาก path (href ยาวสุดที่ตรง) คืน `home` ถ้าไม่ตรงโมดูลใด
- `AppShell` ตั้ง `data-module` ตาม path ปัจจุบัน; `NavigationItem.module` ให้แถบซ้ายแสดงจุดสี
- โมดูลใหม่เพิ่มสีหนึ่งบรรทัดใน `styles.css` และตารางใน `DESIGN.md`

ไม่มีการเปลี่ยนข้อมูล สิทธิ์ หรือ API
