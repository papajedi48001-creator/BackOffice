# ส่งออกข้อมูลทะเบียนบุคลากร และกล่องค้นหาใหม่

## ที่ผู้ใช้ขอ
หน้า `/hr/people` (ทะเบียนบุคลากร): เพิ่มปุ่มส่งออกข้อมูล และออกแบบกล่องค้นหาใหม่ 3 แบบให้เลือก

## การส่งออกข้อมูล
- ปุ่ม "ส่งออกข้อมูล" ได้ไฟล์ CSV (BOM, ทุกช่องอยู่ในเครื่องหมายคำพูด, ค่าขึ้นต้นด้วย = + - @ ถูกกันไม่ให้เป็นสูตร) เปิดใน Excel ได้ ภาษาไทยไม่เพี้ยน ใช้ `csvOf` ตัวเดียวกับการส่งออกอุบัติเหตุหมู่
- คอลัมน์เท่ากับตารางบนหน้า: รหัสบุคลากร, ชื่อ-นามสกุล, ตำแหน่งงาน, ประเภทการจ้าง, หน่วยงาน, เลขประจำตัวประชาชน (แบบปิดบังเท่านั้น), สถานะ
- ได้เฉพาะคนที่แสดงอยู่ตามคำค้นและตัวกรองตอนกด ตัวกรองถูกใช้ซ้ำบนเซิร์ฟเวอร์ด้วยฟังก์ชันเดียวกับหน้าจอ (`filterPeople`)
- ส่งคำค้นใน body ของ `POST /api/hr/people/export` ไม่ใส่ใน URL
- สิทธิ์ (ตรวจบนเซิร์ฟเวอร์): `data.export` ของโมดูล `hr` ทั้งโรงพยาบาล (`canActHospitalWide`) คือ ผู้ดูแลระบบ, ผู้จัดการโมดูลงานบุคคล, ผู้ส่งออกข้อมูลที่ไม่จำกัดหน่วยงาน และรายชื่อยังจำกัดตามขอบเขต `hr.person.read` ของผู้ส่งออก ถ้าไม่มีสิทธิ์ปุ่มไม่แสดงและ API ตอบ 403
- ทุกการส่งออกเขียนบันทึกการตรวจสอบ `hr.people.export` (`exportKind: 'people'`, `rows`) ไม่มีชื่อ คำค้น หรือเลขประจำตัวประชาชนในบันทึก
- ชื่อไฟล์ `people-YYYY-MM-DD.csv` ตามวันที่กรุงเทพฯ

## กล่องค้นหา
ทำภาพตัวอย่าง 3 แบบ (ช่องใหญ่ + ปุ่มเม็ดยา / การ์ดรวมตัวกรอง / แถวเดียว + ปุ่มเปิดตัวกรอง) ให้ผู้ใช้เลือก แล้วทำแบบที่เลือก
